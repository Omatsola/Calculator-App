# Calculator App

A simple and responsive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean user interface.

## Features

- Addition, subtraction, multiplication, and division.
- Clear (AC) and Delete (DEL) functions.
- Decimal number support.
- Keyboard support.
- Dark mode toggle.
- Error handling for division by zero.
- Responsive design.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
